🚀 Projetos em destaque

🏋️ Descomplicando do Movimento

Plataforma SaaS para gestão de personal trainers e alunos.

Uma aplicação completa que reúne diversas ferramentas para gerenciamento de alunos, acompanhamento físico e administração de negócios fitness.

- Gestão de alunos e acompanhamento individual.
- Avaliações físicas e evolução corporal.
- Prescrição e gerenciamento de treinos.
- Monitoramento de sono, fadiga e desempenho.
- Gestão financeira e controle de pagamentos.
- Relatórios e geração de documentos em PDF.
- Notificações e automações.
- Aplicação PWA com experiência otimizada para dispositivos móveis.

Tech: Next.js, React, TypeScript, Node.js, Prisma, PostgreSQL

💈 Glamix

Aplicativo web para gerenciamento de barbearias.

Sistema desenvolvido para modernizar a administração de barbearias, centralizando o gerenciamento de profissionais, clientes e serviços.

- Gestão de barbeiros, funcionários e clientes.
- Controle de agendamentos e filas.
- Histórico de serviços e pagamentos.
- Diferentes níveis de acesso (Admin, Secretária, Barbeiro e Cliente).
- Painel administrativo.
- Interface responsiva e experiência PWA.

Tech: React, Node.js

👕 Cado Malhas

Catálogo digital interativo.

Aplicação desenvolvida para apresentar produtos de forma moderna, intuitiva e interativa, proporcionando uma experiência digital mais prática para os clientes.

- Apresentação digital de produtos.
- Navegação interativa pelo catálogo.
- Interface moderna e responsiva.
- Experiência otimizada para dispositivos móveis.
- Aplicação web instalável como PWA.

📺 NewPlay Manager

Plataforma SaaS para gerenciamento de assinaturas e planos.

Sistema administrativo desenvolvido para facilitar o controle de clientes, assinaturas, planos e operações comerciais.

- Gerenciamento de clientes e assinaturas.
- Cadastro e controle de planos.
- Dashboard administrativo e financeiro.
- Indicadores de receitas, despesas e lucros.
- Organização e automação de faturamento.
- Interface responsiva e PWA.

Tech: React, TypeScript, Vite, Tailwind CSS, PostgreSQL, Netlify Functions
